# Target pack: Cinder Ridge (base-building-rts kit)

The "target" is what a good capture of Cinder Ridge must look like: a small, readable base-building real-time strategy skirmish seen from a high three-quarter top-down camera. Two bases on a highland split by a shallow river, workers hauling amber crystal, a column of units crossing a ford to attack. Original content throughout.

| File | Holds |
|---|---|
| `reference-prompt.md` | The reference image prompt (KIT_PROCESS template) and a title-screen variant. |
| `look-bible.md` | Palette (sRGB hex), shape language, sky and backdrop, theme props, lighting. |
| `moments.md` | The signature capture moments, with ids, what must be in frame, pass criteria. |
| `hud-layout.md` | Every HUD element at 1920x1080 and on a phone (portrait and landscape). |
| `playbook.md` | The genre checklist (no `docs/playbooks/base-building-rts.md` exists yet) and how this kit meets each item. |

Stage note: K5a is the greybox pass (plain shapes). The look named in ROADMAP (`stylizedpbr`) and the props below arrive with the art pass (K5b); the greybox runs on the `toon` look, which is in this genre's `compatible_looks`.
