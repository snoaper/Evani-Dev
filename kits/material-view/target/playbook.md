# Playbook

There is no `docs/playbooks/<genre>.md` for a material viewer. These are the
brief's checks for the viewer (Material catalogue batch 1, critic round 1),
written as playbook items, with how the viewer meets each.

| Item | Why | How the viewer meets it |
|---|---|---|
| Every material reads as itself | A viewer that shows a material wrongly misleads every game that uses it | Each scene's subject is made for its family (shader ball, pouf, bust, pool, ground patch); the recipe looks themselves belong to the recipe stage |
| The same picture on every device | Phones and tablets must look like PC | Low and Ultra show the same scene and subjects; cost is cut in quality steps, never by dropping a subject or the look |
| Each art style keeps the material's detail | A style that flattens the pattern hides the material | The style detail step keeps the pattern inside the style's colours |
| The library is clear | 1,054 rows must be findable | Search, filter chips, categories with ready/total counts; long names end in "..." with a tooltip |
| Nothing placeholder-like, broken, clipped or overlapping | The critic and Chris judge from pictures | Grounded subjects, a floor to the horizon, every streamed model asked for before a review shot, a measured HUD layout at every size |
| No existing game, studio or brand named | All content is original | The style tabs carry our own words; a kit test checks the viewer's data, the page and the catalogue's text against a list of names |
| Not applicable: win, lose, timer, lives | A viewer has no goals | Free roam is the same as play (the test `free_roam_through_every_scene`) |
