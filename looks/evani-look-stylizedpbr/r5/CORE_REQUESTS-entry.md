# Proposed CORE_REQUESTS rows (from ChimpDuty, evani-look-stylizedpbr)

These update the three existing rows `smooth-lighting`, `soft-shadows` and `fur-shells` (Evani.Dev CORE_REQUESTS.md, 2026-10-17) with what was built in the ChimpDuty gap crates. Same 5-column format. Nothing here has been applied to Evani.Dev; the engine half is `look-surface.patch` in this folder.

| Date | From kit | Request | Why the kit needs it | Status |
|---|---|---|---|---|
| 2026-10-17 | Chimp Duty (gap crate `evani-look-stylizedpbr`) | `smooth-lighting`, engine half: evani-render feature `look-surface` (implies `models`, `shadows`). The forward module gets `look_surface.wgsl`, `look_biplanar.wgsl` and `look_fur_surface.wgsl` after model.wgsl; the model pipeline draws `model_lit_vs` / `model_lit_fs`; the material group gains bindings 5 (metallic-roughness, linear), 6 (occlusion, linear), 7 (look detail map), 8 (`ModelSurface` uniform, 16 words) and 9 (look fur clump map); `prepare` lists the metallic-roughness and occlusion textures; the render module declares the `specular` and `surface_params` slots (zero defaults); the look's maps come from its generators `surface.detail` and `surface.clump` (white when a look has none). GTAO needs no hook: it is an evani-fx effect (gap crate `evani-fx-gtao`) | proposed: `look-surface.patch` (line-neutral: every edit to an existing line keeps the line count, new code at file ends; applies to f216906 with `git apply`; byte-identical probe wasm with the feature off, see HANDOVER.md section 6).
